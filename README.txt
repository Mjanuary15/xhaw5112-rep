NEXT LEVEL GAMING & ESPORTS ARENA - RESPONSIVE WEBSITE
=========================================================

This is a student Phase 2 responsive website prototype based on the group proposal.

FILES
-----
index.html          Home / landing page
about.html          About Us page
packages.html       Gaming Packages
experiences.html    Individual Experiences
booking.html        Booking and live quotation calculator
contact.html        Contact page
style.css           Responsive styling
script.js           Mobile menu + quotation calculator

HOW TO RUN
----------
1. Keep all files in the same folder.
2. Double-click index.html, or open it in a browser.
3. Test the navigation on desktop and resize the browser to test mobile responsiveness.
4. Open Book / Quote and select different bookings to test the discount and VAT calculator.

DISCOUNT LOGIC
--------------
1 booking = 0%
2 bookings = 5%
3 bookings = 10%
More than 3 bookings = 15%
VAT = 15% after the discount.

DESIGN

NOTE
----
This is a front-end academic prototype. The contact and booking forms send submissions through Formspree (form ID mnppwgge). No real payment is processed.
